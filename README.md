# 📩 Contact Form

A clean, responsive contact form built using HTML, CSS, and JavaScript. It allows users to enter their contact details, select a reason and priority, and submit a message with validation feedback.

## ✨ Features

* Full Name, Email and Phone fields
* Reason dropdown and Priority selection
* Message box with a 500-character counter
* Required-field and input validation
* Terms and Privacy checkbox
* Clear and Reset functionality
* Loading state and success message
* Light and Dark theme
* Responsive, mobile-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
